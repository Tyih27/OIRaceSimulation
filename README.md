# OI 比赛模拟器

## 启动

项目需要 Node.js 20 或更高版本。存档和排行榜会由本地服务写入项目的 `data/` 目录。

```bash
npm start
```

然后访问终端显示的地址，默认是 <http://127.0.0.1:8080>。

也可以直接双击 `index.html` 游玩：页面会提示存档服务不可用，但可以正常开始新游戏。此时自动存档、读档和排行榜不可用；需要保存进度时，请点击右侧面板的「📋 手动保存」，按弹窗提示把复制到的存档 JSON 保存到 `data/saves/` 目录（文件名会在弹窗中显示）。

开始页支持「📥 导入存档」：可以直接粘贴存档 JSON 内容，或选择 `.json` 文件导入。通过 `npm start` 启动时，导入会直接保存到本地存档目录；直接打开 `index.html` 时，导入只在当前网页中临时生效。

## 数据文件

- 玩家存档：`data/saves/<玩家名哈希>.json`
- 排行榜：`data/leaderboard.json`

启动页会列出所有有效的角色存档，可直接继续或删除。每个规范化后的玩家名对应一个存档槽位；使用同名角色开始新游戏会在确认后覆盖原存档。

玩家存档和排行榜 JSON 默认不提交到版本控制。排行榜首次连接服务时会自动合并浏览器内旧的 `oi_leaderboard` 数据。
