# OI 比赛模拟器

## 启动

项目需要 Node.js 20 或更高版本。存档和排行榜会由本地服务写入项目的 `data/` 目录。

```bash
npm start
```

然后访问终端显示的地址，默认是 <http://127.0.0.1:8080>。

由于浏览器安全限制，直接双击 `index.html` 无法把自动存档写入项目目录，因此不再作为受支持的启动方式。

## 数据文件

- 玩家存档：`data/saves/<玩家名哈希>.json`
- 排行榜：`data/leaderboard.json`

启动页会列出所有有效的角色存档，可直接继续或删除。每个规范化后的玩家名对应一个存档槽位；使用同名角色开始新游戏会在确认后覆盖原存档。

玩家存档和排行榜 JSON 默认不提交到版本控制。排行榜首次连接服务时会自动合并浏览器内旧的 `oi_leaderboard` 数据。
